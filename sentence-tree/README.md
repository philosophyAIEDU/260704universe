# 🌳 문장나무 (SentenceTree)

문장을 입력하면 **주어·서술어·목적어** 같은 문장 성분이 알록달록한 나무(트리)로 펼쳐지는
교실·어학학습용 웹 앱입니다. 국어/영어 문법 수업 판서 대용, 한국어·영어 학습자의
어순 연습용으로 쓸 수 있어요.

- **설치·회원가입·비용 없이** 바로 작동합니다 (로컬 분석, 로마자 발음, 어순 연습, 퀴즈).
- **Gemini API 키**를 넣으면 AI 정밀 분석·단어 뜻·번역·AI 교수님 기능이 켜집니다 (선택 사항).

---

## 1. 내 컴퓨터에서 열어보는 법 (선택)

이 폴더를 그냥 더블클릭해서 여는 것이 아니라, **간단한 서버**로 열어야 합니다.
어렵지 않아요. 딱 한 줄이면 됩니다.

1. 이 폴더(`sentence-tree`)를 컴퓨터에 내려받습니다.
2. **Mac**: `터미널` 앱을 열고 / **Windows**: `명령 프롬프트(cmd)`를 열고, 아래를 입력합니다.

```
cd 폴더위치/sentence-tree
python3 -m http.server 8000
```

(Windows에서 `python3`가 안 되면 `python -m http.server 8000` 으로 해보세요.)

3. 브라우저 주소창에 **http://localhost:8000** 을 입력하면 열립니다.

> 로컬에서 열어보는 건 "미리보기"일 뿐이에요. 학생들과 쓰려면 아래 Netlify에 올리면 됩니다.

---

## 2. Netlify에 올리는 법 (드래그 앤 드롭, 무료)

1. https://app.netlify.com/drop 에 접속합니다. (Netlify 계정이 없으면 무료 가입)
2. **`sentence-tree` 폴더 전체**를 마우스로 끌어서 화면의 점선 상자에 놓습니다.
3. 몇 초 뒤 `https://무작위이름.netlify.app` 주소가 생깁니다. 이 주소를 학생들에게 알려주면 끝!

> 폴더 안에 `index.html` 이 바로 들어 있어야 합니다. (이 폴더는 이미 그렇게 되어 있어요.)
> 압축(zip)해서 올려도 되고, 폴더째 끌어다 놓아도 됩니다.

### 수정한 뒤 다시 올리는 법

1. Netlify에 로그인 → 내 사이트(Site)를 클릭합니다.
2. 왼쪽 메뉴에서 **Deploys** 를 클릭합니다.
3. 수정한 `sentence-tree` 폴더를 Deploys 화면의 점선 상자에 **다시 끌어다 놓으면** 됩니다.
   주소는 그대로 유지되고 내용만 새것으로 바뀝니다.

### 비밀번호로 접근을 제한하고 싶다면

- Netlify의 **비밀번호 보호(Password protection / Site protection)** 기능을 쓰면 됩니다.
  - 내 사이트 → **Site configuration** → **Access & security** (또는 Access control) →
    **Password protection** 에서 비밀번호를 설정합니다.
  - 단, 이 기능은 Netlify 유료 플랜에서 제공됩니다. 무료로 쓰려면
    "주소를 아는 사람만 접속"하는 방식(주소를 학급에만 공유)으로 운영하는 방법이 있어요.

## 3. AI 기능 켜기 (선택)

1. https://aistudio.google.com/apikey 에서 무료 Gemini API 키를 발급받습니다.
2. 앱 오른쪽 위 **⚙️ 설정**을 누르고 키를 붙여넣고 저장합니다.
3. 이제 ✨ AI 정밀 분석, 단어 뜻 보기, 번역, AI 교수님, AI 퀴즈가 작동합니다.

> 🔒 키는 **사용자의 브라우저에만** 저장되며, 구글 외 어디에도 전송되지 않습니다.
> ⚠️ AI 기능을 쓰면 입력한 문장이 구글 서버로 전송됩니다.
> **학생 이름 등 개인정보는 예문에 넣지 마세요.**

## 4. 수업에서 이렇게 써보세요

| 하고 싶은 것 | 누르는 것 |
|---|---|
| 문장 분석 | 문장 입력 → **분석하기** (예문 칩을 눌러도 돼요) |
| 판서처럼 하나씩 보여주기 | **단계별 펼치기** → **다음 ▶** |
| 큰 화면 수업 | **🖥️ 수업 모드** (전체화면 + 글자 확대) |
| 성분 맞히기 게임 | **퀴즈 모드** → 트리의 `?`를 누르고 성분 고르기 |
| 어순 훈련 | **어순 연습** → 카드를 바른 순서로 배열 |
| 칠판 그림 저장 | **PNG 저장** |
| 영어권 학습자용 화면 | 상단 **🌐** 버튼으로 English 인터페이스 전환 |

## 5. 파일 구성 (참고)

```
sentence-tree/
  index.html        화면 뼈대
  netlify.toml      Netlify 설정 (빌드 없음)
  css/styles.css    디자인
  js/app.js         전체 컨트롤러
  js/i18n.js        한국어/English 문구 사전
  js/parser-ko.js   한국어 성분 분석 (조사 기반)
  js/parser-en.js   영어 구조 분석 (근사치)
  js/romanize-ko.js 한글 → 로마자 발음
  js/tree-render.js SVG 트리 그리기
  js/ai-tutor.js    Gemini AI 연동
  js/practice.js    어순 연습·퀴즈
  js/storage.js     브라우저 저장(localStorage)
  js/data.js        레벨별 예문·성분 색상
```

- 개인정보 수집, 회원가입, 광고, 결제 없음. 모든 저장은 사용자의 브라우저(localStorage)에만.
- 자동 분석은 교육용 근사치이며, AI 번역·뜻풀이도 참고용입니다.
